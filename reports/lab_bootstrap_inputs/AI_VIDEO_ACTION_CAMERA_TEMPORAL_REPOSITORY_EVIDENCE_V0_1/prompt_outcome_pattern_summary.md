# Prompt Outcome Pattern Summary

This summary is repository-backed. Prompt clauses are requests, not proof of execution.

## Supported Findings

- Ordered structure improved action organization and readability in CAL-002 Batch02, but did not materially improve physical realism.
- A generic appended causality suffix did not improve results consistently and regressed the impact case in Batch03.
- Action-specific result-first compilation was mixed: the push case improved, while the impact case regressed. The compiler was a compound treatment, so component-level attribution is rejected.
- Explicit identity and scene references often improved identity, composition, or spatial blocking, but did not guarantee force transfer, timing, or grounded recovery.
- Reference-specific PUSH and IMPACT differentiation passed in the bounded CAL-002 C02 pair, but CAL-003 repeatability collapsed asymmetrically toward PUSH and CAL-004/CAL-005 did not establish an IMPACT condition gate.
- Positive timing clauses need measurable onset, contact, consequence, recovery, and an active ending. Broad choreography adjectives and long negative lists did not substitute for that schedule.
- Multi-location choreography in one five-second shot caused spatial jumps, face instability, or visual chaos in SHOT-03.
- Local speed edits helped SHOT-02 V018 because useful impact motion already existed. They did not repair V012 or V003, where contact beats and force chains were structurally absent.
- Short cuts can concentrate existing contact evidence, but complete-MP4 review repeatedly exposed long static tails, delayed reactions, or disconnected aftermath.
- Camera success is independently evidenced most clearly by SHOT-01 V001 and CAL-001 F03 slow push-ins. A camera phrase in a prompt is not an executed camera result.

## Provisional Rules

1. Separate action, camera, and temporal duties in both prompt design and evaluation.
2. Evaluate complete MP4s before promoting a favorable cut window.
3. Treat identity-reference gains and action-causality gains as separate outcomes.
4. Treat command-route changes as confounds unless the experiment controls them.
5. Use edits only to select motion that already exists; do not describe edit rescue as generation success.
6. Replicate favorable single-pair results before production promotion.

## Rejected Overclaims

- `technical success = visual success`
- `readable contact = physically causal reaction`
- `better identity = better action`
- `one favorable reference pair = repeatable reference control`
- `short cut = complete-MP4 success`
- `prompt requests camera motion = camera motion executed`
- `human-selected edit candidate = whole-film final master`
